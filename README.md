# 🏢 Room Booking Service — Сервис бронирования помещений

> Веб-приложение для автоматизации бронирования переговорных комнат, конференц-залов и служебных помещений в офисах и учебных заведениях.

---Ссылка на сайт: https://kuksenkonikodim.github.io/room-booking-service/

## 📋 Основные возможности

| Функция | Описание |
|---------|----------|
| 🔐 **Авторизация** | Вход в систему по логину/паролю |
| 📋 **Просмотр помещений** | Список всех помещений с фильтрацией по вместимости и оборудованию |
| 📅 **Просмотр расписания** | Календарь занятости помещений на день/неделю |
| ✨ **Создание брони** | Выбор времени и помещения → создание брони в 3-4 клика |
| 📜 **Мои бронирования** | История своих будущих и прошедших броней |
| ❌ **Отмена брони** | Отмена своего будущего бронирования |
| ⚙️ **Управление помещениями** | Добавление, редактирование, удаление помещений (админ) |
| 📊 **Статистика** | Просмотр загруженности помещений (админ) |

## 🛠️ Технологический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Frontend** | React + Material-UI | Пользовательский интерфейс |
| **Backend** | Python + FastAPI | REST API сервер |
| **Database** | PostgreSQL | Хранение данных |
| **ORM** | SQLAlchemy | Работа с базой данных |
| **Auth** | JWT | Аутентификация |
| **Hosting** | Vercel + Railway | Деплой |

## 🚀 Запуск проекта

### 1. Клонирование репозитория
```bash
git clone https://github.com/KuksenkoNikodim/room-booking-service.git
cd room-booking-service
2. Запуск backend (Python/FastAPI)
cd backend
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate (Windows)
pip install -r requirements.txt
uvicorn main:app --reload
3. Запуск frontend (React)
cd frontend
npm install
npm start
