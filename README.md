## 📋 Основные возможности

| Функция | Описание |
|---------|----------|
| 📋 Просмотр помещений | Список всех комнат с вместимостью и оборудованием |
| 📅 Просмотр расписания | Таблица всех бронирований |
| ✨ Создание брони | Выбор комнаты, даты и времени |
| 📜 Мои бронирования | Просмотр и отмена своих броней |
| ❌ Отмена брони | Отмена в один клик |
| ⚙️ Управление комнатами | Добавление и удаление комнат (админ) |
| 📊 Статистика | Количество комнат и броней (админ) |

## 🛠️ Технологический стек

| Компонент | Технология |
|-----------|------------|
| Backend | Python + Flask |
| База данных | SQLite + SQLAlchemy |
| Интерфейс | HTML5 + Bootstrap 5 |
