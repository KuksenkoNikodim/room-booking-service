# Room Booking Service — Сервис бронирования помещений

## 📌 Назначение
Веб-приложение для автоматизации бронирования переговорных комнат, конференц-залов и служебных помещений. Позволяет сотрудникам просматривать свободные слоты и бронировать помещения, администраторам — управлять перечнем помещений.

## 🎯 Целевая аудитория
- **Сотрудник** — быстро найти и забронировать свободное помещение
- **Руководитель отдела** — планировать встречи, видеть загруженность
- **Администратор офиса** — управлять помещениями, следить за бронированиями

## 🛠 Технологический стек
| Компонент | Технология |
|-----------|------------|
| Frontend | React + Material-UI |
| Backend | Node.js + Express |
| Database | PostgreSQL + Sequelize |
| API | REST |
| Hosting | Vercel (frontend) + Railway (backend) |

## 🔗 API Endpoints (основные)
| Метод | Endpoint | Описание |
|-------|---------|---------|
| POST | `/api/auth/login` | Вход в систему |
| GET | `/api/rooms` | Список помещений |
| POST | `/api/bookings` | Создание брони |
| DELETE | `/api/bookings/:id` | Отмена брони |

## 👤 Роли и права
- **Пользователь** — просмотр, бронирование, отмена своих броней
- **Администратор** — управление помещениями, просмотр всех броней, статистика
